Proyecto Travel X:

TravelX es una aplicación desarrollado en grupo de planeación de viajes y reservas, desarrollada con Angular (web y móvil) y un backend en Spring Boot.

- Puedes optener una lista de viajes, como en carro tren y/o bus, y reservas de hoteles dependiendo a donde quieras ir con una gran lista de hoteles disponibles dependiendo de tu presupuesto y preferencias (como mascotas o si tiene piscina). 

## Stack Tecnológico

- Frontend Web: Angular 21
- Frontend Móvil: Angular (versión mobile)
- Backend: Java 21 + Spring Boot, empaquetado como WAR
- PDF: jsPDF (generación de documentos)
